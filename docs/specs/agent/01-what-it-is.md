## 1. What it is

The agent is the part of Retaskable that runs on a person's own computer, and where the work happens. Retaskable works through a project's backlog on its own. The backlog is the shared backlog store's ([backlog.md](https://github.com/Retaskable/Retaskable.com/blob/main/docs/specs/backlog.md)), not a file or a list the agent keeps. The agent asks the store for the next item. For each one it starts a headless Claude Code session to implement the next slice of the item and open a PR. It waits for CI (if the repo has any), then starts a separate Claude Code session to review the PR. It merges the PR if the review passes, or sends it back for changes if not. It tells the store what happened at each step, and repeats until the store has nothing left to hand out. **Claude is never idle:** whenever nothing on the roadmap can start, the agent asks the store for a chore (fixing a red main, tidying code, adding tests, hunting bugs, fleshing out specs) and runs it until the usage limit says stop.

The agent has no UI of its own. Everything a person sees is the Expo app ([expo.md](https://github.com/Retaskable/Retaskable.com/blob/main/docs/specs/expo.md)) on retaskable.com, which reads the store and the hub and sends the commands in [cloud.md](https://github.com/Retaskable/Retaskable.com/blob/main/docs/specs/cloud.md) section 6. What the agent does for it:

1. **Setup**: the computer's own checks (Claude Code, git, the code host's CLI), and linking a project when the site sends the command ([first-run-check.md](../first-run-check.md)).
2. **Roadmap work**: it runs the items the store hands it, drafts specs for requests, answers **Ask Claude** (it can press the same buttons a person can, such as launching the game), and plays a build on request.
3. **Live sessions**: it streams what each running Claude session is doing (role, item, current step, recent tool calls, cost) to the hub over the cloud link, live and never stored there.
4. **Questions and playtests**: when an agent has a clarification question, or a slice has changed something a person can see or feel in the game, the agent records it in the store and waits. The answer, or the try-out's result, comes back from the store and resumes the session. What is waiting on a person, and the bell that shows it, are the app's and the store's.
