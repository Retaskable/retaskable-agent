### 6.10 Spec layout

(2026-10-22) A session reads specs a section at a time, so no spec file is bigger than a session needs: every file under `docs/specs/` is at most 40,000 characters (the spec size gate, section 6.2).

- **A split spec.** A spec over the limit is an index plus a folder: `docs/specs/<name>.md` keeps its opening (the title and metadata before the first `##`), then a line saying it's split, then each `##` heading followed by links to that section's files. Each `##` section is its own file in `docs/specs/<name>/`, moved as is: `NN-<slug>.md` (`06-sessions.md`). A section still over the limit splits at its `###` headings, each its own file `NN.M-<slug>.md` (`06.2-implementer.md`), with the text before the first `###` left in `NN-<slug>.md`. A piece still over the limit splits at the paragraph break nearest 35,000 characters into `NN-<slug>-2.md`, listed in the index as "(continued)".
- **References still resolve.** "`<name>.md` section 7" names the index, whose `## 7.` lists the files that hold it. Links in moved text gain `../`, and links to an anchor in the same spec point at the section file that now holds it.
- **Reading one.** `shared/specParts.ts` reads the layout: `specParts` lists an index's section files in order, `wholeSpec` joins them back into the whole text (the start report's spec code, `agent/src/startFiles.ts`), and `sectionFile` finds the file holding a section number (release notes' spec links, `agent/src/releaseNotes.ts`). A hosted backlog reads only the top-level specs as items' specs (`specsAt`), so section files never become items. The MCP `read_spec` tool reads the index or any section file by path ([mcp.md](https://github.com/Retaskable/Retaskable.com/blob/main/docs/specs/mcp.md)).
- **Splitting one.** `node --import tsx scripts/splitSpec.ts docs/specs/<name>.md` splits a spec this way and refuses to leave any file over the limit; a spec that's already split is skipped. The spec drafter splits a spec it grows past the limit the same way (`prompts/drafter.md`), and the spec scout reads the index, then only the sections it needs.
